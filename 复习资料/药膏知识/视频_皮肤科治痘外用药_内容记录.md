## 内容总结

### 🎯 视频核心信息

视频系统介绍了 **8 款**常见外用祛痘药，按痘痘类型分组推荐：
- **闭口粉刺黑头**：阿达帕林、维A酸乳膏、班赛
- **红肿痘痘**：阿达帕林、克林霉素凝胶、夫西地酸乳膏、甲硝唑凝胶、班赛、克林霉素甲硝唑擦剂
- **痘坑痘印**：班赛、阿达帕林、喜辽妥、积雪苷霜软膏

每款药按统一维度介绍：适合类型 / 涂抹时机 / 涂抹方法 / 刺激性 / 人群选择 / 注意事项。

### 📌 关键使用原则

1. **联合使用**：抗生素类（克林霉素、夫西地酸、甲硝唑）不建议单独使用，应与班赛或阿达帕林联合
2. **建立耐受**：阿达帕林、班赛都需要"建立耐受"，前几次先涂保湿霜再点涂
3. **分时涂药**：
   - 早上 BPO（班赛）/ 克林霉素 / 夫西地酸
   - 晚上 阿达帕林 / 维A酸乳膏
4. **不要用棉签涂药**
5. **严格防晒**（使用阿达帕林、维A酸期间）
6. **班赛最大优势**：不会产生耐药性，可长期维持治疗
7. **孕妇禁用慎用**：维A酸类（阿达帕林、维A酸乳膏）、甲硝唑、克林霉素甲硝唑擦剂
