# 手机壁纸学习提示卡片 Skill

一个用于生成「学习提醒」手机壁纸的标准化 Skill / SOP。

核心目标：把**学习主题、原始角色图、手机型号与分辨率、锁屏/主屏幕安全区、视觉风格**整合成一张可以长期使用的手机学习提醒壁纸。学习主题默认同等级呈现，不推断用户未给出的用途、排序或分组。用户要求保留原图人物时，使用直接叠加而非重绘。

## 核心原则

> 手机壁纸不是海报。

普通海报只考虑画面本身；手机壁纸还必须考虑状态栏、日期、大号时间、小组件、手电筒、相机、Home 指示条、主屏幕 App 图标、Dock、iOS 自动缩放与裁剪。

## 标准流程

1. 收集学习主题。
2. 确认用户是否指定显示顺序或分组；未指定时统一呈现。
3. 获取原始角色图和风格参考图。
4. 获取手机型号、分辨率和用途（锁屏/主屏幕）。
5. 规划安全区。
6. 若要求原图保真，先以等比例缩放加必要裁切适配目标屏幕，再叠加卡片和文字；不得拉伸或重画人物。
7. 生成第一版。
8. 在真实手机中设置并截图。
9. 根据截图微调；优先整体平移，不轻易放大主体。
10. 核对人物、文字和卡片边缘后输出最终壁纸。
