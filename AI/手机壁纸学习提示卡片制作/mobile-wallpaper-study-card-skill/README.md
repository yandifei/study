# 手机壁纸学习提示卡片 Skill

一个用于生成「学习提醒 / Tech Stack」手机壁纸的标准化 Skill / SOP。

核心目标：把**学习关键词、技术优先级、原始角色图、手机型号与分辨率、锁屏/主屏幕安全区、视觉风格**整合成一张可以长期使用的手机学习提醒壁纸。

## 核心原则

> 手机壁纸不是海报。

普通海报只考虑画面本身；手机壁纸还必须考虑状态栏、日期、大号时间、小组件、手电筒、相机、Home 指示条、主屏幕 App 图标、Dock、iOS 自动缩放与裁剪。

## 标准流程

1. 收集技术栈关键词。
2. 区分 PRIMARY / SECONDARY。
3. 获取原始角色图和风格参考图。
4. 获取手机型号、分辨率和用途（锁屏/主屏幕）。
5. 规划安全区。
6. 生成第一版。
7. 在真实手机中设置并截图。
8. 根据截图微调。
9. 优先整体平移，不轻易放大主体。
10. 输出最终壁纸。
