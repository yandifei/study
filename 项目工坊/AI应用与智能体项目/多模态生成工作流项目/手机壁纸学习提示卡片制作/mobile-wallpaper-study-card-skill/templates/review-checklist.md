# 出图验收清单

## 内容
- [ ] 学习主题全部正确
- [ ] 没有多余主题
- [ ] 没有遗漏主题
- [ ] 标题正确
- [ ] 激励语正确

## 构图
- [ ] 顶部有安全留白
- [ ] 标题不贴顶部
- [ ] 人脸不在大时间区域
- [ ] 学习主题卡片清晰
- [ ] 底部不拥挤
- [ ] 卡片没有压住脸、手、躯干、腿脚等人物关键区域
- [ ] 用户指定的卡片位置已被遵从
- [ ] 卡片标题、主题、图标、分隔线和边框均未裁切
- [ ] 大字号在目标手机尺寸下仍清晰、行距足够

## 原图保真（适用时）
- [ ] 使用用户提供的原始文件作为底层，而不是重绘人物
- [ ] 人物的脸、五官、姿势、服装、手脚和画风未改变
- [ ] 横向与纵向使用同一缩放比例，没有拉伸人物
- [ ] 如有裁切，只裁掉允许的非关键边缘
- [ ] 已在 100% 预览下与原图比对脸、眼睛、手和人物轮廓

## 锁屏
- [ ] 日期不挡关键内容
- [ ] 时间不挡人脸
- [ ] 小组件不挡标题
- [ ] 手电筒不挡激励语
- [ ] 相机不挡学习主题卡片
- [ ] Home 指示条不挡文字

## 主屏幕
- [ ] App 图标不会严重遮挡学习主题
- [ ] Dock 不挡关键信息
- [ ] 小组件不会压角色脸

## 实机回测
- [ ] 已在真实手机中设置
- [ ] 已截图检查
- [ ] 已根据截图微调
- [ ] 微调优先整体平移
- [ ] 没有无意义放大主体
- [ ] 输出尺寸与目标分辨率完全一致
