# Prompt 模板

## 第一版生成

```text
请制作一张 {{PHONE_MODEL}} 手机学习提醒壁纸。

目标分辨率：
{{RESOLUTION}}

用途：
{{LOCK_OR_HOME}}

视觉风格：
{{STYLE}}

原始角色图：
{{REFERENCE_IMAGE}}

原图处理方式：
{{ARTWORK_MODE}}

标题：
{{TITLE}}

副标题：
{{SUBTITLE}}

学习主题：
{{STUDY_TOPICS}}

激励语：
{{MOTIVATION}}

布局要求：
1. 顶部保留手机系统 UI 安全区。
2. 标题位于系统时间/组件下方。
3. 将全部学习主题放进一张清晰的科技 UI 卡片；卡片位置遵从 {{CARD_POSITION}}，同时避开角色脸、手、躯干和系统 UI。
4. 角色位于中间偏右，或按底图留白调整。
5. 激励语位于安全区内的空白位置。
6. 人物脸部不得进入锁屏大时间区域。
7. 底部重要内容不得被相机、手电筒、Dock 或 Home 指示条遮挡。
8. 文字必须清晰。
9. 不要为了填满屏幕而放大内容。
10. 卡片标题、每项主题与边框必须完整，不得裁切；{{TEXT_SIZE_PREFERENCE}}。
11. 若为“原图保真”，必须直接使用原图为固定底层：仅允许等比例缩放、必要裁切以及卡片/文字叠加；不得重画、补画、替换或修饰人物，横向和纵向不得使用不同缩放比例。
```

## 实机截图修订

```text
Image A 是原始壁纸。
Image B 是用户真实手机截图。

只使用 Image B 判断系统 UI 覆盖区域。
不要把 Image B 中的时间、日期、状态栏、相机、手电筒等系统 UI 画进最终图。

保持 Image A 的：
- 角色
- 风格
- 学习主题
- 字号
- 卡片大小
- 相对布局

若 Image A 为原图保真作品，人物本身不得改变；只可修改卡片、文字、边框或整体取景。不得通过重新生成来修订人物。

根据用户要求整体移动主体。

例如：
将“学习提醒”以及学习提醒以下全部主体内容整体向上移动一点，使标题靠近 8:40 小组件区域底部。

不要放大。
```
