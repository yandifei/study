# SKILL：手机壁纸学习提示卡片制作

## 1. 定位

把用户想长期记住的学习主题做成适合手机使用的提示卡片壁纸。

它只服务于学习提醒与视觉排版，不推断用户未给出的用途、排序或分组。

成图应满足：

- 学习主题一眼可见；
- 文字、角色图与背景协调；
- 适配指定手机型号与使用场景；
- 重要内容避开系统 UI；
- 可根据实机截图继续校正。

当用户提供角色原图并要求保留人物时，成图还必须保留原图中的人物面部、姿势、服装和画风，不得因制图流程而变形或被重画。

## 2. 收集输入

优先使用用户已经给出的信息；只追问会直接影响出图的问题。

### 学习主题

- 收集需要显示的学习主题；
- 默认全部同等级显示，不擅自排序或分层；
- 只有用户明确给出显示分组或顺序时，才按其要求排版。

主题应简短。壁纸负责提醒，不负责教学。

### 图片与风格

- 是否有底图、角色原图或风格参考；
- 是否要保留人物姿势、服装和配色；
- 是否允许重新构图。

### 原图保真模式

用户出现“在原图上实现”“人物/脸不能变”“保留原人物”等明确要求时，启用**原图保真模式**：

- 原图是固定底层，只能做等比例缩放、必要裁切和卡片/文字叠加；
- 不使用会重绘、补画、替换或重构人物的生成式编辑；
- 人物的脸、五官、头发、姿势、服装、手脚和画风必须保留；
- 只在用户明确允许重新构图或重画时，才可以改变角色图。

不要把“优先编辑原图”理解成“可以重画原图”。原图保真时，应直接在原始文件上叠加设计元素。

### 设备与场景

- 品牌、型号、分辨率；
- 锁屏、主屏幕或两者；
- 是否需要标题与激励语。

如果用户已提供足够信息可以出图，不要为了套模板继续追问无关内容。

## 3. 默认排版

### 顶部安全区

留出大面积空白，只放淡色科技线条、HUD、点阵或轻渐变。不要放核心文字或角色脸。

### 标题区

可选标题如“学习提醒”或“学习卡片”，放在系统时间/组件下方，不贴顶部。

### 学习主题卡片

将全部学习主题放入一张清晰的科技 UI 卡片，使用统一字号、图标和分隔线。默认放在不遮挡角色脸、手、躯干、腿脚等主体关键部位，且能避开系统 UI 的区域；可根据底图改为左侧、右侧或下方。

用户明确指定卡片位置时，以用户指定的位置为准；先保证人物脸和关键肢体不被遮挡，再通过卡片透明度、尺寸和内边距解决可读性。用户认可右下角时，不要自行改到其他区域。

### 尺寸适配与不变形规则

将原图适配目标分辨率前，先比较宽高比。**禁止分别拉伸宽度和高度**，尤其不得用非等比缩放来“铺满屏幕”。

1. 使用同一个缩放比例缩放原图；
2. 比例不一致时，默认保留完整高度并从左右非关键区域做少量居中裁切；
3. 若裁切会损害用户指定区域，先征得同意再采用留白或背景延展；不要复制人物、拼接条带或补画人物；
4. 输出前确认横向、纵向缩放比例一致（仅允许像素取整误差）。

这条规则用于防止人物脸部被压扁或拉长。

### 角色与激励语

角色通常放中间偏右，脸部避开锁屏大时间区域。激励语可选，放在远离底部系统按钮的位置。

## 4. 锁屏与主屏幕适配

锁屏避让日期、大号时间、小组件、手电筒、相机和 Home 指示条。

主屏幕避让 App 图标、小组件、搜索栏和 Dock。需要双场景时，分别出图更稳妥。

第一版生成后，应在真实手机中设置并截图；修订时以截图判断系统 UI 覆盖。若比例合理，优先整体平移主体，不随意放大。

## 5. 内容与 Logo

- 只显示用户给出的学习主题，不遗漏、不新增；
- 标题与激励语保持简短；
- Logo 可少量使用，但一致性优先于官方还原；
- 不塞学习计划、主题解释或课程介绍。

## 6. Prompt 结构

Prompt 应说明：

1. 指定手机型号、分辨率和用途；
2. 标题、学习主题与可选激励语；
3. 底图、角色、配色和视觉风格；
4. 顶部安全区、主题卡片与角色的位置；
5. 需避开的系统 UI。

## 7. 实机修订

原壁纸是编辑目标，实机截图仅用于判断覆盖区域。不要把截图中的时间、日期、状态栏、相机或手电筒画进最终图。

保留用户未要求改变的角色、学习主题、字号、卡片尺寸和相对布局。优先整体平移，不要无意义放大。

原图保真模式下，修订只改变卡片、文字、边框或整体取景；不得借修订机会重新生成或修饰人物。

## 8. 验收

- 所有学习主题准确且清晰；
- 没有额外主题；
- 标题、角色与卡片不拥挤；
- 重要内容不被目标场景的系统 UI 遮挡；
- 原图保真时，人物脸、手、服装和姿势与原图一致，没有变形、补画或重绘痕迹；
- 卡片标题、每项主题与边框均未被裁切，字体在目标手机尺寸上可读；
- 原图与成图的角色区域在 100% 预览下比对过；
- 输出尺寸与目标分辨率完全一致，且人物没有非等比拉伸；
- 完成实机回测后，再按截图微调。
