后端图像接口文档：https://t.alcy.cc/docs.html

竖屏图片（使用 acg-images-mp）：moemp, mp, tx, xhl, ysmp, mikump
非竖屏图片（使用 acg-images）：pc, ai, bd, fj, lai, moe, ys, miku
自适应图片（使用 acg-images）：ycy, moez, ysz, mikuz
动图（使用 acg-images）：acg
旧端点（当前官方分类未列出，建议验证后使用）：aimp, fjmp

| 短代码 | 类型名称   | 详细说明                                                                                                             |
| :----- | :--------- | :------------------------------------------------------------------------------------------------------------------- |
| pc     | PC壁纸     | 适合电脑显示器等宽屏设备的壁纸。                                                                                     |
| ai     | AI生成     | 由人工智能工具（如NovelAI、Midjourney等）生成的图片；当前官方分类页未列出，但端点仍可用。                            |
| aimp   | AI竖屏     | 旧分类，AI生成图中适配手机竖屏的尺寸；当前官方分类页未列出，建议验证后使用。                                         |
| bd     | 白底极简   | PC大小，背景纯白，画面仅有一个人物，留白极简风格。                                                                   |
| fj     | 风景       | 自然或城市风光景观类图片。                                                                                           |
| fjmp   | 风景竖屏   | 旧分类，风景类图片裁剪为竖屏尺寸；当前官方分类页未列出，建议验证后使用。                                             |
| lai    | 软萌表情   | 在LINE、微信、QQ等聊天软件中流行的表情包。源自画师しめさば的原创角色困倦涂鸦（如打呼噜「すーすー」），并非官方套图。 |
| moe    | 萌图       | 日文「萌え」，指可爱、治愈的动漫风格图片。                                                                           |
| moemp  | 萌图竖屏   | 萌图类图片裁剪为竖屏尺寸。                                                                                           |
| mp     | 手机壁纸   | 手机竖屏壁纸，适合移动设备；旧文档曾误标为“横屏壁纸”，当前官方分类为手机竖版壁纸。                                   |
| tx     | 头像       | 正方形比例（1:1），适合用作社交平台头像的图片。                                                                      |
| xhl    | 软萌狐     | 接口本意是星空/星海，但由于抓取或标签错误，实际返回的多为软萌大头狐狸图。                                            |
| ys     | 原神横屏   | 《原神》相关二次创作图片，且为横屏比例。                                                                             |
| ysmp   | 原神竖屏   | 《原神》相关二次创作图片，且为竖屏比例，适合手机壁纸。                                                               |
| ycy    | 自适应     | 根据访问设备自动返回横图（桌面端）或竖图（移动端）。                                                                 |
| moez   | 萌版自适应 | 萌系/二次元风格图片，根据访问设备自动适配横图或竖图。                                                                |
| ysz    | 原神自适应 | 《原神》游戏主题图片，根据访问设备自动适配横图或竖图。                                                               |
| mikuz  | 初音自适应 | 初音未来主题图片，根据访问设备自动适配横图或竖图。                                                                   |
| miku   | 初音横屏   | 初音未来主题的横版壁纸。                                                                                             |
| mikump | 初音竖屏   | 初音未来主题的手机竖版壁纸。                                                                                         |
| acg    | 随机动图   | 返回 MP4 格式的动态图片，非静态图。                                                                                  |
