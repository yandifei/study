## 第二部分：快速选择指南（AstrBot 场景）

按"部署 AstrBot + 性价比 + 国内访问"排序：

1. **想要官方一键部署** → **雨云**。AstrBot 官方已上架雨云应用商店，提供一键部署入口与官方论坛教程（见第四部分），最省折腾。
2. **要香港机房 + 便宜（同事推荐）** → **桔风云**：香港特惠 2C2G/15M **¥22/月**（不限流量），或香港 CN2 A区 2C2G/10M ¥30.80/月。新商家无公开评测，**务必月付试水**，不要年付（见第三部分）。
3. **要极致便宜（接受美西 140~170ms 延迟）** → **RackNerd $21.99/年**（约 ¥158），或蹲黑五神价（历史 $10.60/年）；想更低月付可看 **Rabisu $2.47/月**（机房在土耳其等地，延迟更高）。
4. **要稳定大厂** → **DigitalOcean $4/月**、**Vultr $3.50/月**、**腾讯云香港轻量 ¥38/月**（大厂但 20M 带宽 + 512G 流量）。
5. **国内访问速度第一** → 腾讯云/阿里云/华为云国内轻量（新用户 ¥38~99/年），但**必须备案**且备案期间关站 1~4 周（见第十部分）。
6. **AstrBot 资源需求不高**：1~2 核 + 2G 内存足够，优先保证"稳定在线 + 网络延迟"，不用为峰值性能多花钱。

## 第八部分：风险提示与使用须知

- **线路性质**：RackNerd 属于普通国际线路（非 CN2 GIA）。国内晚高峰（20:00-23:00）可能出现丢包、延迟升高，这是平价海外 VPS 的通病。
- **访问失败与被墙机制（国内直连境外网站，什么时候打不开？）**：域名在境外注册 + 服务器在境外，国内用户无需 VPN、也无需备案即可直连访问——这是正常状态。会失败的情形：① **服务器 IP 被墙**（连接直接丢包；廉价 VPS 的共享 IP 被邻居滥用连累是常见原因）；② **域名被墙**（DNS 污染返回假 IP，或 TLS 握手时 SNI 被识别后连接被重置）；③ 内容违规被举报进入黑名单；④ 普通国际线路晚高峰严重丢包导致超时（不是被墙，但体感一样）。判断方法：用 **itdog.cn / ping.pe** 做全国多节点测速——国内大面积不通而国外节点正常，基本就是被墙。自救：**换 IP**、**换域名**、套 **Cloudflare** 兜底。另：本档案针对正常建站/机器人场景；若用途是给国内用户提供"翻墙"代理，被墙是必然结果且违反国内法规。
- **换 IP 政策（RackNerd）**：客户中心提供自助换 IP 功能，开通后 **72 小时内首次免费**，之后每次约 $3。换 IP 前需结清未处理工单。
- **流量翻倍玩法**：RackNerd 促销套餐支持流量翻倍——在 LowEndTalk 官方活动帖评论区回复订单号（Order Number + Invoice ID），或开工单申请，免费。
- **数据备份**：廉价 VPS 一般不含自动快照备份，建议加购官方 Backup 附加项，或自行定时远程备份。

## 第十部分：备案与域名必读（国内 vs 海外服务器）

**核心结论**：备案只和"服务器在中国大陆内地"绑定。用境外服务器（含香港、美国）**不需要备案**，域名解析后即可直接使用。域名本身也不需要备案——只有网站落到国内服务器上才需要。

**1. 什么情况要备案**
- 服务器在中国大陆内地（阿里云/腾讯云国内区等）→ 必须 ICP 备案，未备案域名会被服务商拦截、无法解析到国内服务器。
- 服务器在境外（香港、美国、日本等）→ **无需备案**。域名只需在注册商处完成实名认证。
- 从海外迁回国内 → 需补办首次备案（关站 1~4 周）；从国内迁到海外 → 可主动注销备案，此后无备案负担。

**2. 首次备案期间网站能用吗？**
- **不能上线**：备案期间域名必须保持关站，不能解析、不能访问，禁止以"测试"名义上线。
- 但**服务器不会停**：可以开机、用 IP 登录管理、提前部署环境，只是网站不能通过域名对外服务。
- 时长：服务商初审约 1~3 个工作日 + 管局审核（法定上限 20 个工作日，通常 5~20 个工作日，各省不同：广东约 8~15 个工作日、北京约 15~17 个工作日）。全程约 **1~4 周**。
- 个人备案仅限非经营性内容（博客、个人主页），做电商/付费服务需企业备案。

**3. 换服务器需要重新备案吗？**
- **同一服务商内**换服务器、升级配置、换机房 → **不用重新备案**。
- **换服务商**（如阿里云→腾讯云）→ 不用从零备案，只需在新服务商办"**接入备案**"：备案号不变，审核期间一般**可保持网站访问**（与首次备案不同）；接入成功后，再到原服务商"取消接入"。**顺序必须是先接入新商、再取消旧商**。
- 若取消接入后长期没有新接入商，管局会**注销备案**；注销后要再备案就得重走首次流程（再次关站）。

**4. 备案有有效期吗？**
- 备案号**没有固定到期时间**，长期有效。但必须持续满足：① 备案域名要实际解析到备案服务商的国内服务器并正常使用（长期空挂或指向境外会被取消接入、甚至注销）；② 主体信息（负责人、手机号、地址）变更要及时办变更备案；③ 内容合规，违规会被取消接入/注销；④ 备案通过后 30 天内还需办理**公安备案**。

**5. 企业备案 vs 个人备案**

| 对比项 | 个人备案 | 企业备案 |
| :--- | :--- | :--- |
| **主体** | 身份证 | 营业执照（公司/个体户；个体户归属各省口径不一，提交前咨询管局或服务商） |
| **材料** | 身份证正反面、人脸核验、域名证书 | 营业执照、法人身份证、授权委托书（非法人经办时）、盖章核验单、视频核验/幕布拍照 |
| **审核时长** | 通常 5~20 个工作日 | 通常 7~25 个工作日（差距不大，省份是主要变量；企业材料被退回补正的概率更高） |
| **网站名称** | 禁用"公司/商城/平台/官网"等商业词 | 可用公司名/品牌名，需与营业执照名称或经营范围匹配 |
| **可做内容** | 仅非经营性（博客、展示） | 可经营性（电商、SaaS、支付）；涉前置审批行业另需许可证 |

> 结论：企业备案材料更多、核验更严，**换来的是可以合法经营**。个人备案承载公司业务被抽查到会注销备案并关站。

**6. 换服务器的完整流程（域名怎么办？）**

换服务器 ≠ 重新备案。备案绑定的是"主体 + 域名 + 接入商"，分四种情形：

| 情形 | 流程 | 域名和备案号 |
| :--- | :--- | :--- |
| **A. 同一服务商内换服务器/机房** | **什么都不用做** | 域名、备案号都不动，DNS 解析改指新 IP 即可 |
| **B. 国内换国内**（如阿里云→腾讯云） | ① 在新商提交"接入备案"（主体信息必须与原备案一致）→ 审核 1~20 个工作日，期间网站一般可正常访问；② 接入成功后改解析；③ 再到原商"取消接入" | 域名全程不动；备案号不变，只换接入商 |
| **C. 国内 → 海外** | 域名解析改指境外 IP 即可使用（免备案）；原备案可主动注销，或放着等其被取消接入 | 域名不动；备案号注销后消失 |
| **D. 海外 → 国内** | 先走首次备案（关站 1~4 周），通过后才能解析到国内服务器 | 域名不动；重新获得备案号 |

**顺序口诀**：换商 = 先接入新商 → 改解析 → 再取消旧商。只有"备案被注销"才需要重走首次备案（再次关站）。
