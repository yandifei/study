## 二、核心知识点整理

### 2.1 高清放大的使用场景

- **场景一：承接洗图工作流**
  - 上节课JoyCaption提示词反推洗图跑出来的角色效果不错，但比较模糊
  - 直接拿去做真人AI短剧视频生成效果不好（人太糊）
  - 需要先进行高清放大处理

- **场景二：日常图片高清化**
  - 手头有比较模糊的图片，直接单独拿过来进行高清放大
  - 前面不接入文生图工作流，直接用加载图像节点输入模糊图片即可

- **效果表现**：
  - 衣服上的材质纹理细节被很好地高清放大出来
  - 原本模糊的纹理边缘变得非常硬朗、清晰可见

### 2.2 模型安装方法

1. 百度网盘找到"第五节课 seed vr2 高清放大"文件夹
2. 完整下载文件夹
3. 打开启动器 → 点击根目录 → 进入 `models` 文件夹
4. 将下载的文件夹拖入models目录，完成覆盖安装

### 2.3 工作流整体结构

**两种使用方式**：
1. **文生图+高清放大**：在之前讲过的文生图基础之上，生图之后加高清放大节点，实现生成图片直接高清放大
2. **单独高清放大**：前面不接工作流，直接用加载图像节点输入模糊图片，单独进行高清放大

**关键节点**：共三个核心节点（seedVR2相关节点包）

**节点获取方式**：
- 用UP主网盘整合包：已包含节点包
- 纯净版整合包：没有这三个节点，需在ComfyUI管理器中搜索 `seed vr two` 下载安装

### 2.4 基础文生图搭建（复习）

```
┌──────────────┐
│ UNet加载器    │ ← ZImageTurbo 模型
└──────┬───────┘
       │ model
┌──────▼──────────────────────────┐
│           K采样器                 │
│  步数=9, seed=1, 采样器=EulerFlow│
│  (移位=3)                         │
└──┬────────┬──────────┬──────────┘
   │positive│negative  │latent(出)
   ▼        ▼          ▼
┌────────┐┌────────┐ ┌────────┐
│CLIP文本││CLIP文本│ │空Latent│ 768×1280竖图
│编码(正)││编码(负)│ │        │
└───┬────┘└───┬────┘ └────────┘
    │ clip      │ clip
┌───▼────┐ ┌───▼────┐
│加载CLIP│ │加载CLIP│ ← 千问3，类型=Lumina 2（或千问image）
└────────┘ └────────┘

输出：VAE解码 → 加载VAE(AE模型) → 图片
```

**参数设置**：
- 步数：9
- seed值：1
- 宽高：768×1280（竖图）
- 采样算法：EulerFlow，移位数值=3

### 2.5 高清放大节点搭建

```
文生图输出(VAE解码后的图片)
         │
         ▼
┌──────────────────┐
│ seedVR2 放大节点  │ ← 核心高清放大节点
│ (video放大模型)   │
└──┬───────────┬───┘
   │ model     │ vae
   ▼           ▼
┌────────┐ ┌────────┐
│加载模型  │ │加载VAE  │ ← 放大专用模型和VAE
│(放大模型)│ │        │
└────────┘ └────────┘
         │
         ▼ 放大后的图片
    ┌──────────┐
    │ 保存图像   │
    │ /图像对比  │
    └──────────┘
```

**搭建要点**：
- VAE解码后的图片直接连接到seedVR2放大节点的图像输入
- 放大节点需要加载对应的放大模型和VAE
- 放大完成后输出高清图片，可保存或用图像对比节点查看

### 2.6 放大模型选择

| 模型 | 参数量 | 精度 | 说明 |
|------|--------|------|------|
| 模型一 | 30亿 | FP16 | 显存需求较低，效果稍弱 |
| 模型二（推荐） | 70亿 | FP8 | 效果更好，UP主推荐选择 |

**注意事项**：
- UP主只准备了上述两个模型，只能用这两个
- 想用其他模型可去魔搭社区或其他社区搜索下载
- **如果选择了未下载的其他模型，点击运行时会消耗魔法工具里的流量去下载**，注意不要选错
- 本教程选择最底下的70亿参数量FP8模型

### 2.7 高清放大参数详解

| 参数 | 设置值 | 说明 |
|------|--------|------|
| **blocks to swap** | 32（70亿模型） | 缓解显存压力的关键参数；30亿模型填0~32，70亿模型填0~36；数值越高显存压力越小，但运行时间越长；不需要填到最大，70亿填32即可 |
| **设备选择** | CPU | 选择CPU可进一步减少显存压力 |
| **放大分辨率（宽）** | 2048（2K） | 想要2K输入2048，想要4K输入4096；放越大显存压力越高；一般2K够用，4K可能显存爆 |
| **放大分辨率（高）** | 2048（2K） | 与宽度对应，4K则填4096 |
| **batch size** | 1 | 只放大一张图片，设为1即可 |

**blocks to swap 参数原理**：
- 根据选择的模型参数量填写对应区间
- 作用：有效缓解电脑显存压力
- 权衡：数值越高 → 显存压力越小，但工作流运行时间越长
- 建议：不需要填到区间最大值，取中间值即可（如70亿模型填32，不必填36）

**其他参数**：底下的参数不需要动。

### 2.8 效果演示方法

**为了更直观看出高清放大效果**：
1. 在文生图输出和高清放大节点之间，加一个"缩放图像"节点
2. 选择按像素缩放，将像素量调成约0.8
3. 这样会在生成图片基础上手动降低画质，让高清放大的效果更加明显
4. 用图像对比节点查看放大前后对比（需开启节点2.0显示版本）

**实际效果**：
- 头发丝变得根根分明，非常清晰
- 眼睫毛可以看得很清楚
- 嘴唇上面的褶皱都还原出来了
- 整体效果很好

### 2.9 工作流衔接与组合使用

**与上节课提示词反推工作流衔接**：
- 上节课JoyCaption反推工作流生成的真人AI短剧角色形象比较模糊
- 直接拿去跑视频质量不好
- 解决方法：把上一期的工作流复制过来，将VAE解码出来的图片直接连接到高清放大节点
- 提示词反推→生图→高清放大，无缝衔接，完成图片超精化处理

**ComfyUI核心理念**：
- 学会ComfyUI后，每个工作流都可能成为之后工作中可以随便替换的模块
- 就跟搭积木一样，灵活组合
- 这也是为什么ComfyUI是玩AI必学的工具

### 2.10 常见疏漏与排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 图像对比节点看不到对比 | 只连了放大后节点，放大前节点漏接 | 把放大前的图片也连接到图像对比节点 |
| 图像对比节点不显示 | 未开启节点2.0显示版本 | 开启节点2.0显示版本 |
| 运行时自动下载模型消耗流量 | 选择了未预置的其他模型 | 只选用网盘提供的两个模型（30亿FP16/70亿FP8） |
| 显存不足/爆显存 | blocks to swap太低或放大分辨率太高 | 调高blocks to swap；选CPU；降低放大分辨率（如2K而非4K） |
| 纯净版找不到seedVR2节点 | 未安装节点包 | 在ComfyUI管理器搜索seed vr two下载安装 |
