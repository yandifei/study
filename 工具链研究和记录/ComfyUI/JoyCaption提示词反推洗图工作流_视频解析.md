## 二、核心知识点整理

### 2.1 提示词反推洗图的使用场景

- **场景一：风格/内容复刻**
  - 看到一张非常好看的图片，想要一张风格相似、内容相近的图片
  - 不需要手动观察图片、构思提示词
  - 工作流根据上传图片自动反推提示词，然后进行生图

- **场景二：真人短剧角色形象设定（规避侵权）**
  - 做真人短剧时不知道角色形象怎么设定
  - 找一张很帅的男明星照片（如张贺霖），但不能直接使用（涉及侵权）
  - 把照片放进工作流自动洗图，跑出一张形象相近的帅气男角色
  - 洗出来的图可拿去做真人短剧，不涉及侵权
  - 后续可用千问编辑给角色换衣服、做定妆照

### 2.2 模型安装方法

| 模型类型 | 来源 | 说明 |
|----------|------|------|
| 生图模型 | 第二节课 zimage turbo | 已安装过的无需重复安装 |
| 反推提示词模型 | 本节课网盘文件夹 | 需额外安装 |

**安装步骤**：
1. 百度网盘下载本节课的反推提示词模型文件夹
2. 打开启动器 → 点击根目录 → 进入 `models` 文件夹
3. 将下载的文件夹拖入models目录空白处，松开鼠标完成覆盖
4. 安装完成

### 2.3 工作流整体结构

**四大区域**：
1. **图片输入区**：加载待反推的图片，控制图像尺寸
2. **模型加载区**：UNet/CLIP/VAE三剑客 + Lora + 反推模型
3. **采样区**：K采样器 + 空Latent + VAE解码 + 图像输出
4. **提示词反推区域**（变化最大）：JoyCaption反推 + 结果查看 + 文本编码 + 自定义提示词合并

> 本质上是第二节课image turbo的工作流，只是把提示词输入区改成了加入提示词反推节点，并不会变得特别复杂。

### 2.4 基础工作流快速搭建

**模型加载区**：

```
┌──────────────┐
│ UNet加载器    │ ← 选 ZImageTurbo 模型
└──────┬───────┘
       │ model
┌──────▼───────┐
│ Lora加载器    │ ← image table distill 蒸馏Lora（提速），强度调低
└──────┬───────┘
       │ model
┌──────▼──────────────────────────┐
│           K采样器                 │
│  步数=9, CFG=1, 采样器=EulerFlow │
│  (移位=3), 精度=BF16             │
└──┬────────┬──────────┬──────────┘
   │positive│negative  │latent(出)
   ▼        ▼          ▼
(提示词反推区) (条件零化) (VAE解码→输出)

三剑客（固定要有）：
┌──────────┐ ┌──────────┐ ┌──────────┐
│UNet加载器 │ │CLIP加载器 │ │VAE加载器  │
└──────────┘ └──────────┘ └──────────┘

采样算法：EulerFlow（移位数值调成3）
```

**搭建要点**：
- ZImageTurbo使用UNet加载器（不是Diffusion model loader）
- 三剑客固定要有：UNet加载器、CLIP加载器、VAE加载器
- Lora选image table distill蒸馏Lora，起提速作用，强度调低
- 采样算法用EulerFlow，移位数值调成3

### 2.5 提示词反推区域搭建（核心）

**节点连接顺序**：

```
┌─────────────────────────────────────────────────────────┐
│                    提示词反推区域                          │
│                                                           │
│  ┌─────────────┐    反推结果    ┌─────────────┐         │
│  │  JoyCaption  │──────────────→│  Show Text   │  (查看反推结果)│
│  │  (反推核心)   │                └─────────────┘         │
│  └──────┬──────┘                                          │
│         │ 反推的文本                                        │
│         ▼                                                  │
│  ┌─────────────┐                                          │
│  │ 多文本联合    │←─── 自定义提示词(Text Any Input)        │
│  │ (合并两段文本)│                                          │
│  └──────┬──────┘                                          │
│         │ 合并后的完整提示词                                 │
│         ▼                                                  │
│  ┌─────────────┐                                          │
│  │ CLIP文本编码  │──→ K采样器 positive(正面条件)            │
│  └─────────────┘                                          │
│                                                           │
│  负面条件处理：                                              │
│  ┌─────────────┐    ┌─────────────┐                      │
│  │ CLIP文本编码  │──→│  条件零化     │──→ K采样器 negative │
│  └─────────────┘    └─────────────┘   (防止空置报错)      │
└─────────────────────────────────────────────────────────┘
```

**各节点作用详解**：

| 节点 | 作用 | 说明 |
|------|------|------|
| **JoyCaption** | 提示词反推核心节点 | 加载反推模型，根据输入图片自动反推出提示词 |
| **Show Text** | 查看反推结果 | 让你知道反推出来的提示词到底是什么 |
| **CLIP文本编码** | 文本转机器可读 | 反推结果输入到这里，编码后连接K采样器正面条件 |
| **条件零化** | 防止负面条件空置报错 | K采样器负面条件必须有输入，不打算填负面提示词时用这个节点 |
| **Text Any Input** | 自定义提示词输入 | 想加入自己的描述时用这个节点输入 |
| **多文本联合** | 合并两段文本 | 将自定义提示词和模型反推的提示词合并成一整段输出 |

**自定义提示词合并方法**：
- 不想百分百按照反推结果生图，想加自己的东西时使用
- 例如想让男人戴帽子，在Text Any Input输入"这男人头上有个帽子"
- 不能直接连到CLIP文本编码，必须通过多文本联合节点合并
- **权重控制**：自己输入的内容放在前面，提示词权重占比更高；可根据需求选择谁在前

### 2.6 模型选择清单

| 节点 | 选择的模型 | 注意事项 |
|------|-----------|----------|
| UNet加载器 | ZImageTurbo | 沿用第二节课模型 |
| CLIP加载器 | 千问 34B | 类型换成 **Lumina** 或 **千问image** |
| VAE加载器 | AE模型 | 换成对应的AE模型 |
| Lora加载器 | image table distill 蒸馏Lora | 提速用，强度调低 |
| JoyCaption反推模型 | 文件夹内自动选好 | 按开头方法安装后即可使用 |

### 2.7 图片输入区搭建

```
┌──────────┐    ┌──────────┐    ┌──────────────┐
│ 加载图像   │───→│ 图像缩小   │───→│ 获取图像尺寸   │
│ (待反推图) │    │ (按最长边) │    │              │
└──────────┘    └─────┬────┘    └──┬────────┬──┘
                       │             │ width  │ height
                       │ 处理后的图   ▼        ▼
                       │         ┌──────────────┐
                       │         │   空Latent    │ (宽高自动同步)
                       │         └──────────────┘
                       │
                       └──→ 连接到 JoyCaption 反推模块的图像输入
```

**要点**：
- 图像缩小节点按最长边缩放，设为1280
- 获取图像尺寸节点将宽高同步到空Latent，无需手动调整
- 原图（或缩小后的图）必须连接到JoyCaption反推模块的图像输入接口

### 2.8 K采样器参数设置

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样步数 | 9 | 对应ZImageTurbo模型 |
| CFG | 1 | 调低防止炸图 |
| 采样器 | EulerFlow | 通过采样算法节点指定，移位=3 |
| 精度 | BF16 | 手动换成BF16，其他参数基本不用调 |

### 2.9 使用演示与效果调试

**操作步骤**：
1. 在加载图像节点上传需要反推的图片（如男明星照片）
2. 确认K采样器步数=9、CFG=1
3. 点击运行
4. 用图像对比节点查看原图vs生成图的直观对比

**效果表现**：
- 衣服、首饰、发型等细节尽可能还原
- 可能有部分元素未完全还原（如项链）

**缺失元素补充方法**：
- 在Text Any Input节点手动输入想要的内容，如"男人脖子戴着项链"
- 重新生成，大概率会补上

**成品用途与限制**：
- 洗出来的图可完全用于真人AI短剧的男角色，不涉及侵权
- 后续可用千问编辑给角色换衣服、做定妆照
- **但生成图偏模糊，不推荐直接拿去做真人AI短剧生成**
- 模糊图片拿去跑视频，质量不会很好
- 需要先进行高清放大处理（下节课内容）

### 2.10 常见疏漏与排查

| 问题 | 原因 | 解决 |
|------|------|------|
| K采样器报错 | 负面条件空置 | 加条件零化节点连接负面条件 |
| 图像对比节点没发挥作用 | 未开启节点2.0显示版本 | 开启显示版本 |
| 图像对比只显示一张图 | 原图未连接 | 把原图也连接到图像对比节点 |
| 生成图比例不对 | 空Latent宽高未同步 | 加图像缩小+获取图像尺寸节点同步宽高 |
| 反推结果看不到 | 未加Show Text节点 | 添加Show Text节点连接反推输出 |
