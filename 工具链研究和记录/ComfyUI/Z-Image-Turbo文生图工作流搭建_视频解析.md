## 二、核心知识点整理

### 2.1 模型安装方法

**下载内容**（网盘model文件夹下）：
1. `diffusion models` — 生图大模型
2. `text encoders` — 文本编码器
3. `VAE` — VAE模型
4. `LoRA` — LoRA模型（可选，后面课程会用到）

**安装步骤**：
1. 下载后复制（或剪切）这四个文件夹
2. 打开启动器 → 点击"根目录" → 找到ComfyUI本地部署根目录
3. 进入根目录下的 `models` 文件夹
4. 将四个文件夹移动到这里（已安装会提示同名文件夹，选择不替换即可）
5. **重启ComfyUI**后即可正常使用

### 2.2 文生图工作流搭建流程

**核心思路**：以K采样器为中心，逐步连接所需节点。

```
                    ┌─────────────┐
                    │  UNet加载器  │ ← 选ZImageTurbo模型
                    └──────┬──────┘
                           │ model
┌──────────┐    positive  ┌▼──────────┐    latent    ┌───────────┐
│CLIP文本编码│────────────→│  K采样器   │────────────→│ VAE解码   │
│(正面提示词)│             │ (核心生图)  │             └─────┬─────┘
└──────────┘             └─────▲───────┘                   │
                               │ latent                      ▼
┌──────────┐    negative      │                    ┌──────────────┐
│CLIP文本编码│─────────────────┘                    │  预览图像/保存  │
│(负面提示词)│                                         └──────────────┘
└──────────┘
     ▲
     │ clip
┌──────────┐         ┌──────────┐
│CLIP加载器 │         │空Latent   │ ← 画布尺寸(宽/高)
│(千问3_4B) │         │(SD3)     │
└──────────┘         └──────────┘
                           ▲
                           │
                    ┌──────────┐
                    │VAE加载器  │ ← 选对应AE模型
                    └──────────┘
```

**搭建步骤详解**：

1. **K采样器**：双击空白处添加，核心生图节点，图片从无到有都在这里实现
2. **UNet加载器**：从K采样器的model接口拉出，选择ZImageTurbo模型
3. **正/负面CLIP文本编码**：从K采样器的positive/negative接口拉出，各需要一个
4. **SD3空Latent**：从K采样器的latent_image接口拉出，作为绘画画布
5. **CLIP加载器**：从CLIP文本编码器的clip接口拉出，选择ZImageTurbo适配的千问clip_3_4B模型
6. **VAE解码**：从K采样器的latent输出接口拉出，将潜空间数据解码成可见图像
7. **VAE加载器**：从VAE解码的vae接口拉出，选择对应AE模型
8. **预览图像/保存图像**：从VAE解码的image接口拉出，预览或保存到本地

### 2.3 采样算法与参数设置

**EulerFlow采样算法节点**：
- 作用：一定程度上影响K采样器的绘画方式
- 加上这个节点会让出图结果更加好看
- 连接到K采样器的sampler_name接口

**K采样器参数**：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 采样步数 | 8 ~ 9 | Z-Image Turbo加速模型，步数少即可出好图 |
| CFG | 1 | 新模型CFG设1就有好效果 |
| 采样器 | EulerFlow | 通过采样算法节点指定 |

**画布尺寸（空Latent）**：
- 示例：768 × 1280（竖图，约16:9比例）
- 宽高决定最终生成图片的尺寸

### 2.4 节点分组（Ctrl+G）

- 按住Ctrl + 鼠标左键拖动框选多个节点
- 按 `Ctrl+G` 打组
- 分组命名：
  - **模型加载区**：UNet加载器、CLIP加载器、VAE加载器
  - **提示词输入区**：正/负面CLIP文本编码器
  - **采样区**：K采样器、空Latent、VAE解码、预览/保存图像

> 运行按钮也可以按住前面的六个小点拖动位置。

### 2.5 运行效果

- **首次运行**：约21秒（包含加载模型时间）
- **后续运行**：约15秒（模型已加载在显存中）
- **生成质量**：人体结构正确、发丝细腻、手指形态正确，质量很高
- **提示词遵循**：能准确遵循中文提示词，如"发丝凌乱蓬松还遮面，尽显凌乱美"

### 2.6 基础节点认识

#### 采样区

| 节点 | 作用 | 比喻 |
|------|------|------|
| **K采样器** | 最核心的生图节点，图片从0到有都在这里完成 | 绘画机器 |
| **空Latent** | 提供绘画的画布，宽高决定生成图片尺寸 | 画布 |
| **VAE解码** | 将K采样器生成的潜空间数据解码成人类可看懂的图像 | 显影机 |
| **预览/保存图像** | 预览生成结果 / 保存到本地 | — |

#### 提示词区

| 节点 | 作用 |
|------|------|
| **CLIP文本编码（正面）** | 将正面提示词转换成模型能识别的条件，告诉K采样器想要什么 |
| **CLIP文本编码（负面）** | 将负面提示词转换成排除条件，告诉K采样器不想要什么（丑的、坏的、质量低的等） |

> Image Turbo对中文理解比较到位，甚至知道"赛亚人悟空"是什么，说明模型训练中包含了相关内容。

#### 模型加载区

| 节点 | 加载内容 | 作用 | 比喻 |
|------|----------|------|------|
| **UNet加载器** | 生图大模型（ZImageTurbo） | 决定K采样器能画什么、画出来的质量怎么样 | 工作流的大脑 |
| **CLIP加载器** | 语言翻译模型（千问clip_3_4B） | 将输入的提示词翻译成机器可以读懂的语言 | 翻译员 |
| **VAE加载器** | VAE模型（对应AE模型） | 驱动VAE解码，将机器生成的内容解码成人眼可识别图片 | 显影机驱动 |

> 没有UNet加载器，K采样器作为绘画机器就相当于脑子空空的，什么都画不出来。挑选大模型时尽量选质量好的。

### 2.7 负面提示词使用建议

- 负面提示词**可填可不填**
- Z-Image Turbo这类新模型很多时候不填负面提示词也能生成质量不错的画面
- 需要时可填比较通用的负面提示词（如低质量、变形、模糊等）
