## 二、核心知识点整理

### 2.1 模型清单与安装

**模型总大小**：约27G，全部需要下载，少一个都不行

| 模型类型 | 说明 |
|----------|------|
| diffusion models | 高噪声模型 + 低噪声模型（两个都要，工作流都会用上） |
| VAE | 视频解码用 |
| Lora | 两个（高噪声Lora + 低噪声Lora），都要下载 |
| Clip | 文本编码用 |

**安装步骤**：
1. 百度网盘下载本节课全部模型文件
2. 打开启动器 → 点击根目录 → 进入 `models` 文件夹
3. 将下载的所有文件全部拖入models目录
4. 完成安装

### 2.2 工作流整体结构

**与文生图/图生图的共同点**：
- 三剑客：UNet加载器、CLIP加载器、VAE加载器
- Lora + 采样算法 → 输入K采样器
- 提示词输入 → CLIP文本编码
- K采样器生成后 → VAE解码 → 输出

**核心差异：二次采样（两个K采样器）**

Wan 2.2文生视频模型采用二次采样方法，设置两个K采样器串联：

| 阶段 | 名称 | 作用 |
|------|------|------|
| 第一次采样 | **高噪声阶段** | 决定视频大致框架和结构、全局色彩分布、主体物理运动轨迹是否合理；画面非常混乱/模糊，相当于起草稿 |
| 第二次采样 | **低噪声阶段** | 在已确定的轮廓和动作基础上，集中降噪、补充细节：人物皮肤纹理、衣服褶皱、光影、环境真实质感；相当于完成视频生成 |

> 高噪声K采样器的输出直接连接到低噪声K采样器的输入，低噪声结束后进行VAE解码。

**降噪底层逻辑**：AI视频/图像生成的本质是从纯粹的雪花噪点，一步步清晰化，最终变成高清图像和视频，这个过程叫降噪。打草稿阶段噪声多，所以叫高噪声阶段。

### 2.3 高噪声采样区搭建

```
┌──────────────┐
│ UNet加载器    │ ← T2V 高噪声模型 (Text to Video)
└──────┬───────┘
       │ model
┌──────▼───────┐
│ Lora加载器    │ ← 1.2.2 T2V 高噪声 Lora
│ (仅模型)      │
└──────┬───────┘
       │ model
┌──────▼──────────────────────────┐
│      高级版 K采样器 (高噪声)      │
│  总步数=4, CFG=1, 0~2步          │
│  采样算法=SD3 (数值=8)            │
└──┬────────┬──────────┬──────────┘
   │positive│negative  │latent(出)→连低噪声K采样器
   ▼        ▼          ▼
┌────────┐┌────────┐ ┌──────────────┐
│CLIP文本││CLIP文本│ │混元视频空Latent│ 控制视频尺寸
│编码(正)││编码(负)│ │              │
└───┬────┘└───┬────┘ └──────────────┘
    │ clip      │ clip
┌───▼────┐ ┌───▼────┐
│加载CLIP│ │加载CLIP│ ← UMT5 FP8 模型
└────────┘ └────────┘

VAE加载器 ← 1.2.1 版本VAE
```

**搭建要点**：
- 使用**高级版K采样器**（不是普通版）
- 采样算法用**SD3**（不再是EulerFlow，因为生视频模型不是Z-Image Turbo）
- 采样算法数值换成**8**
- 模型选**T2V高噪声**模型（T2V = Text to Video 文生视频）
- Lora选**1.2.2 T2V高噪声**Lora
- CLIP选**UMT5 FP8**模型
- VAE选**1.2.1**版本
- 空Latent用**混元视频空Latent**（不是图片空Latent，这个节点控制视频生成尺寸）

### 2.4 低噪声采样区搭建

**搭建方法**：直接复制高噪声采样区，粘贴一份，然后做以下修改：

| 修改项 | 高噪声区 | 低噪声区 |
|--------|----------|----------|
| UNet模型 | T2V高噪声 | **Low低噪声** |
| Lora模型 | 1.2.2高噪声Lora | **1.2.2低噪声Lora** |
| 输入来源 | 混元视频空Latent | **高噪声K采样器的输出** |
| 输出去向 | → 低噪声K采样器 | → VAE解码 |

**连接关系**：
- 高噪声K采样器采样完之后，直接输出给低噪声K采样器，进行二次采样
- 低噪声K采样器结束后，进行VAE解码
- **两个K采样器都需要连接CLIP和正负面条件**（不要只连一个）
- VAE解码后输出图像（视频帧）

### 2.5 视频输出与插帧

**Video Combine 节点**：
- 作用：将K采样器生成的一张张图片全部合并成视频
- 本质：ComfyUI生成视频其实是在生成指定张数的图片，通过这个节点合成在一起变成视频

**插帧节点**：

| 项目 | 设置 | 说明 |
|------|------|------|
| 初始生成帧数 | 8帧/秒 | 帧数调太高非常耗显存，时间也很长 |
| 插帧倍数 | ×2（或×3） | 通过插帧节点将帧数翻2~3倍 |
| 最终帧数 | 16帧/秒（×2后） | 视频播放更丝滑 |

**插帧的好处**：
- 减少显存占用
- 提高工作流生成视频速度
- 保证生成视频帧数足够，播放效果丝滑

### 2.6 帧数计算与视频尺寸

**总帧数计算公式**：

```
总帧数 = 目标时长(秒) × 每秒帧数 + 1
```

> 最后的+1是因为需要有一个空帧。无论什么模型，计算长度时都是时间×帧数，最后还要加1。

**示例**：
- 想要5秒视频，每秒8帧 → 5 × 8 + 1 = **41帧**
- 如果用16帧/秒，想要5秒 → 16 × 5 + 1 = **81帧**

**视频尺寸**：1024 × 640（在混元视频空Latent节点设置）

### 2.7 K采样器参数设置

| 参数 | 高噪声K采样器 | 低噪声K采样器 | 说明 |
|------|--------------|--------------|------|
| 总步数 | 4 | 4 | Lora标注"4步"，四步内完成采样 |
| CFG | 1 | 1 | 调低防止炸图 |
| 开始/结束步数 | 0 ~ 2 | 2 ~ 1万 | 一次采样0~2步，二次从2步接力；实际到4步结束，填1万也不影响 |
| 随机种子 | 随机 | **与一次采样器保持一致** | 二次采样器种子固定，和一次采样器相同 |

**步数接力原理**：
- 一次采样器在第2步结束（完成高噪声草稿阶段）
- 二次采样器从第2步开始，像接力棒一样继续降噪
- 总共降噪步数是4步，二次采样器就算结束步数填100万，也是到第4步就结束
- 所以二次采样器的结束步数可以不用改

### 2.8 运行调试与常见错误

**运行前检查清单**：
1. **返回剩余噪波**：要打开（在高噪声K采样器设置中）
2. **UNet数据类型**：要改一下（差点漏掉的设置）
3. **二次采样器的噪波**：**必须关闭**！二次采样不需要添加新的噪波，直接沿用一次采样的噪波种子即可。忘记关闭会导致运行出错。

**效果表现**：
- 只经过VAE解码出来的视频（8帧/秒）有一顿一顿的感觉，不流畅
- 经过插帧节点×2后，视频明显丝滑很多
- 一次采样的画面非常糊，只是在给整个视频定基调、定框架
- 二次采样在一次采样的结构以内进行细化，补充人物皮肤纹理、衣服褶皱、环境真实质感

```
┌─────────────────────────────────────────────────────────────┐
│                      模型加载区                                │
│  UNet(高噪声T2V)  UNet(低噪声Low)  CLIP(UMT5 FP8)  VAE(1.2.1)│
│  Lora(高噪声)      Lora(低噪声)      SD3采样算法(数值=8)      │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    提示词输入区                                │
│  正面提示词 → CLIP文本编码 ──┐                                │
│  负面提示词 → CLIP文本编码 ──┤  两个K采样器都要连接正负面条件  │
└──────────────────────────────┼───────────────────────────────┘
                               │
┌──────────────────────────────▼───────────────────────────────┐
│                      高噪声采样区 (草稿阶段)                     │
│  混元视频空Latent(1024×640, 41帧) → 高级K采样器(0~2步, seed) │
│  返回剩余噪波=打开                                              │
└──────────────────────────────┬───────────────────────────────┘
                               │ 输出(带噪波的潜空间)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                    低噪声采样区 (细化阶段)                       │
│  高级K采样器(从2步开始, seed与高噪声一致, 关闭额外噪波)         │
└──────────────────────────────┬───────────────────────────────┘
                               │ 输出
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                      视频输出区                                │
│  VAE解码 → Video Combine(8帧/秒) → 插帧节点(×2=16帧/秒)     │
│         → Video Combine(最终视频) → 保存/预览                  │
└─────────────────────────────────────────────────────────────┘
```
