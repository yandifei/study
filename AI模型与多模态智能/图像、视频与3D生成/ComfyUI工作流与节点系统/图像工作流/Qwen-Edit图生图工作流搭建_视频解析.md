## 二、核心知识点整理

### 2.1 千问编辑图生图的应用场景

- **建立角色资产库**：生成角色三视图（正视图/侧视图/背视图），极具实战意义
- **多图编辑**：双图或三图联动编辑
- **风格转换**：图片转绘成不同绘画风格
- **动作姿态调整**：修改图中人物的动作姿势
- **服装更换**：更换图中人物的服装
- **多图互动合成**：如让两个女生拥抱在一起

> 角色三视图可用于AI视频生成时保持角色一致性。

### 2.2 模型安装方法

1. 百度网盘找到"第三节课 千问Ed图生图"文件夹（含工作流）
2. 完整下载整个文件夹，解压后得到四个文件夹
3. 打开启动器 → 点击根目录 → 进入 `models` 文件夹
4. 将下载的四个文件夹拖入models文件夹空白处，进行文件覆盖
5. 安装完成（与上一期安装方式相同）

### 2.3 图生图工作流搭建

**工作流分区**：模型加载区、提示词输入区、采样区、图片输入区

**核心节点连接顺序**：

```
┌──────────────────┐
│ Diffusion model  │ ← 选千问image edit 2511
│ loader (大模型)   │
└────────┬─────────┘
         │ model
┌────────▼─────────┐
│  Lora加载器(仅模型)│ ← 选千问编辑4 steps（提速过滤）
└────────┬─────────┘
         │ model
┌────────▼──────────────────────────────────────┐
│              K采样器 (核心生图)                  │
│  步数=4, CFG=1, 采样器=EulerFlow(移位=3)       │
└───┬──────────┬──────────┬──────────┬──────────┘
    │ positive │ negative │ latent   │ latent(输出)
    ▼          ▼          ▼          ▼
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│千问编辑 │ │千问编辑 │ │空Latent│ │VAE解码 │
│文本编码 │ │文本编码 │ │(SD3)   │ │        │
│(正面)   │ │(负面)   │ │宽高同步 │ └───┬────┘
└───┬────┘ └───┬────┘ └────────┘     │
    │ clip      │ clip                  ▼
┌───▼────┐ ┌───▼────┐            ┌────────┐
│加载CLIP│ │加载CLIP│            │预览/保存│
│千问2.5 │ │千问2.5 │            │图像    │
│类型=千问│ │        │            └────────┘
│image   │ │        │
└────────┘ └────────┘

图片输入区：
┌────────┐  ┌────────┐  ┌────────┐
│加载图像1│  │加载图像2│  │加载图像3│  (最多3张)
└───┬────┘  └───┬────┘  └───┬────┘
    │            │            │
    ▼            ▼            ▼
  连接到正/负面文本编码框的image接口

辅助节点：
┌────────────┐     ┌────────────┐
│ 图像缩放     │────→│ 获取图像尺寸 │────→ 空Latent(宽/高)
│ (按最长边)   │     │            │
└────────────┘     └────────────┘

┌────────────┐
│ CFG归一化    │ → 防止高CFG值导致色彩溢出/炸图
└────────────┘

┌────────────┐
│ 采样算法     │ → EulerFlow（一定程度影响绘画方式）
└────────────┘
```

**搭建步骤详解**：

1. **K采样器**：核心生图工具，从这里开始搭建
2. **Diffusion model loader**：加载生图模型（注意不是UNet加载器，架构更新，适配新模型）
3. **千问编辑专用文本编码框**：正/负面条件各需要一个（必须用千问编辑的专用文本编码框）
4. **加载CLIP**：连接到文本编码框的clip接口
5. **加载VAE**：连接到文本编码框的vae接口
6. **加载图像**：图生图的核心输入节点，将图片上传到这里，输入到文本编码框；支持最多3张图像
7. **Lora加载器（仅模型）**：连接在模型加载器和K采样器之间，起提速作用
8. **采样算法**：EulerFlow，影响K采样器绘画方式
9. **CFG归一化**：防止高CFG值导致色彩溢出/对比度太高/炸图
10. **空Latent（SD3）**：画布，设置宽高
11. **VAE解码**：将潜空间数据解码成可见图像
12. **预览图像/保存图像**：查看和保存结果

### 2.4 模型选择清单

| 节点 | 选择的模型 | 注意事项 |
|------|-----------|----------|
| Diffusion model loader（大模型） | 千问 image edit 2511 | — |
| Lora加载器 | 千问编辑 lining 4 steps | 对应K采样器步数也要调成4 |
| 加载CLIP | 千问 2.5 | **千问3用不了**，必须选千问2.5 |
| 加载VAE | 千问 image VAE | — |
| 加载CLIP的"类型"参数 | 千问 image | 必须手动调整，容易遗漏 |

### 2.5 K采样器参数设置

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样步数 | 4 | 对应Lora的4 steps |
| CFG | 1 | 调低防止炸图；配合CFG归一化节点使用 |
| 采样器 | EulerFlow | 通过采样算法节点指定；**注意不要选成SD3的采样算法，否则会异常** |
| 移位 | 3 | EulerFlow采样算法的参数 |

### 2.6 Lora加载器的作用（提速原理）

- **本质**：给模型参数设置过滤条件
- **为什么能提速**：
  - 大模型假如有20亿参数量，不放Lora时，所有参数（无论用得上用不上）都会流入K采样器，跑图花费很长时间
  - Lora加载器设置过滤条件，符合条件的参数才经过Lora流入K采样器，不符合的被保留
  - 流入K采样器的参数量变小，从而达到提速效果
- **型号对应**：Lora名称中的"4 steps"表示四步，K采样器的步数也要对应调成4

### 2.7 CFG归一化的作用

- **问题**：CFG值调得很高时，生成图片会出现色彩溢出、对比度非常高，即"炸图"
- **解决**：加上CFG归一化节点，可有效防止这种情况发生
- **配合**：CFG值本身也建议调低（如设为1）

### 2.8 使用方法与技巧

**单图编辑（改人物动作姿势）**：
1. 按住Ctrl多选不需要的加载图像节点，按 `Ctrl+B` 关闭（bypass），只保留一张图
2. 在正向提示词输入：`将图像一中的看着镜头微笑`（引用"图像一"来指定参考哪张图）
3. 负面提示词可填可不填（千问编辑模型训练质量高，不填质量也不会差；有明确不想出现的内容再填）
4. 点击运行

**常见错误排查**：
- K采样器显示异常时，检查采样算法节点是否放错（如放成SD3的采样算法，应该是EulerFlow）

### 2.9 图像比例问题与解决方案

**问题**：空Latent默认宽高是1:1，但输入图片可能是竖图（如9:16），导致生成出来的图片比例与原图不一致。

**解决方案**（添加两个辅助节点）：

1. **图像缩放节点**（按边模式）：
   - 设置目标尺寸（如1280）
   - 按图像最长边进行缩放，宽度按比例同步缩短
   - 缩放后宽高比保持不变

2. **获取图像尺寸节点**：
   - 获取经过缩放处理后的图像宽度和高度
   - 将宽度和高度同步连接到空Latent的width和height接口
   - 之后不需要手动调整空Latent大小，生成图片自动与输入图片宽高比例一致

### 2.10 其他玩法

| 玩法 | 操作方法 | 注意事项 |
|------|----------|----------|
| **角色三视图** | 提示词输入"生成图一中女生的角色三视图，分别为正视图、侧视图和背视图" | 图像尺寸调成横图16:9，竖图很难塞下三视图，比例会崩 |
| **图片转绘** | 在文本编码器直接输入想转绘的风格 | 只要千问编辑训练到的绘画风格都可以转绘 |
| **换衣服** | 上传图片，提示词说清楚换什么衣服 | — |
| **多图互动合成** | 上传多张图片（最多3张），提示词描述互动内容（如"这两个女生拥抱在一起"） | 最多支持3张参考图 |
