## 二、核心知识点整理

### 2.1 入门必须掌握的三件事

1. **工作流在哪里打开和保存？** — 左上角主菜单的文件选项，或工作流标签旁的操作菜单
2. **任务怎样运行和中断？** — 右上角蓝色运行按钮启动，红色叉号停止（Ctrl+Alt+Enter）
3. **遇到问题以后去哪里查看日志？** — 左下角命令行图标打开日志面板，第一时间查看报错原因

### 2.2 AI 辅助排查问题技巧

> 遇事不决先问AI。

- 碰到看不懂的功能或工作流报错时，把**界面截图 + 报错信息 + ComfyUI日志**一起发给AI，再简单说明自己做了什么、想实现什么
- 提供的信息越完整，AI越容易定位问题、缩小排查范围
- 使用 Workbody、Codex 等 AI coding agent 时，可让它们直接检查运行环境、配置文件和报错信息
- 日志面板右上角有**复制按钮**，可一键复制报错信息粘贴给AI

### 2.3 顶部区域详解

**状态栏**
- `Idle`：当前处于空闲状态，无工作流执行中；运行时会显示任务状态
- 工作流名称：当前工作流的标题

**多标签页**
- ComfyUI支持同时打开多个工作流，像浏览器标签一样显示在顶部
- 标签旁的 **+** 号：新建空白工作流

**图形模式**
- 当前使用"图形"（节点图编辑模式），是ComfyUI最核心的工作方式
- 可直接在画布中查看节点连接关系、调整参数、搭建工作流
- **应用模式**（测试中）：隐藏复杂节点界面，只保留可操作参数，适合把工作流包装成小工具；入门阶段暂不用关注

**工作流操作菜单**（图形右侧小箭头展开）

| 功能 | 说明 |
|------|------|
| 重命名 | 修改当前工作流名称 |
| 复制 | 快速复制当前工作流生成新副本（保留原版+尝试新调整时非常有用） |
| 添加到书签 | 收藏工作流，方便快速查找 |
| 保存 | 直接记录修改，覆盖原文件 |
| 另存为 | 保留原文件，创建新副本到工作流库 |
| 导出 | 把工作流文件保存出来，方便备份或分享 |
| 导出API | 面向开发者，将工作流转换成API调用格式 |
| 清除工作流 | 仅清空画布节点，**不删除**已保存的文件（未保存的修改会丢失！） |
| 删除工作流 | 直接移除当前工作流，**使用需谨慎** |

> **好习惯**：修改工作流前先保存；想尝试新效果时先复制一份再在副本上调整。

### 2.4 主菜单详解

#### 文件菜单

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 新建 | — | 打开新的空白画布 |
| 打开 | Ctrl+O | 载入已有工作流 |
| 保存 | Ctrl+S | 记录当前修改 |
| 另存为 | — | 保留原文件，生成新副本 |
| 导出 | — | 保存工作流文件用于备份/分享 |
| 导出API | — | 程序调用用的API工作流格式 |

> **建议**：每完成一个阶段就按一次 Ctrl+S，特别是修改了节点、模型或重要参数后。不要等全部做完再保存。

#### 编辑菜单

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 撤销 | Ctrl+Z | 撤销错误操作（移动错节点、删错连线等） |
| 重做 | Ctrl+Y | 恢复刚刚撤销的操作 |
| 复制 | Ctrl+C | 复制选中节点 |
| 粘贴 | Ctrl+V | 粘贴节点 |
| 全选 | Ctrl+A | 选中画布中全部节点 |
| 清除工作流 | — | 清空画布所有节点（不删除已保存文件，但未保存内容会丢失） |
| 刷新节点定义 | R | 新增模型文件或安装新节点后，让ComfyUI重新读取节点和模型信息 |
| 卸载模型 | — | 释放显存，不删除已下载的模型文件 |
| 卸载模型和执行缓存 | — | 释放显存+清理运行缓存；清理后下次运行需重新加载模型，首次执行会稍慢 |

#### 视图菜单

| 功能 | 说明 |
|------|------|
| 底部面板 | 控制底部区域显示/隐藏 |
| 专注模式 | 隐藏部分菜单，让画布拥有更大操作空间 |
| KJ Node | 开源社区大佬KJI做的自定义节点合集（一堆实用小工具集合），是否显示取决于整合包是否已整合 |
| 主题 | 仅改变界面外观，不影响节点参数和出图效果；建议学习时保持默认深色主题 |
| Nodes 2.0 | 新版节点显示系统，优化显示效果和交互体验；部分第三方节点尚未完全适配可能有兼容问题，入门建议先用默认 |
| 浏览模板 | 打开工作流模板中心，提供官方和第三方示例工作流；缺少模型会给出提示 |

> **模板学习建议**：不要打开模板后直接运行。先顺着节点连线观察整个流程——模型从哪加载？提示词传到哪个节点？图像经过哪些步骤？最后从哪输出？理解数据流后，别人的工作流才能变成你能修改和创造的工具。

#### 设置菜单

- **Convey分类**：开发者模式（API调用/插件开发用，入门暂不需要）、错误提示（**建议保持开启**，节点执行失败时直接提示出错位置）、工作流保存方式、执行预览等
- **管理扩展**：管理自定义节点在前端中的菜单、面板和快捷功能，可选择开启/关闭某个节点
- 安装第三方扩展后可能增加对应设置选项

#### 帮助菜单

- 官方文档、社区问题反馈、版本信息等入口
- 普通操作问题优先查看官方文档

### 2.5 左侧工具栏

| 面板 | 功能 |
|------|------|
| 素材面板 | 查看已生成的图片、视频及其他输出内容 |
| 节点面板 | 搜索ComfyUI自带节点和已安装第三方节点，找到后直接拖入画布 |
| 模型面板 | 显示当前ComfyUI已识别到的本地模型 |
| 工作流面板 | 快速查找和切换已保存的工作流 |
| 模板面板 | 打开工作流模板中心 |

> 不同版本左侧图标顺序可能不同，鼠标停留在图标上会自动显示名称。

**左下角四个入口**

| 图标 | 功能 |
|------|------|
| 问号 | 帮助功能 |
| 命令行窗口 | **日志面板（重点记住）** |
| 键盘 | 查看快捷键 |
| 齿轮 | 进入设置页面 |

**日志面板的重要性**：
- 模型加载失败、节点缺失、显存不足、工作流执行异常——**第一时间打开日志查看原因**
- 每次运行时，模型加载过程、节点执行时间、错误信息都会记录在这里
- 右上角复制按钮可一键复制报错信息，粘贴给AI辅助排查

### 2.6 常用快捷键速查

| 快捷键 | 功能 |
|--------|------|
| Ctrl + S | 保存当前工作流 |
| Ctrl + O | 打开工作流 |
| Ctrl + Z | 撤销 |
| Ctrl + Y | 重做 |
| Ctrl + C / Ctrl + V | 复制/粘贴节点 |
| Ctrl + A | 全选节点 |
| Ctrl + Enter | 快速执行工作流 |
| Ctrl + Alt + Enter | 快速停止执行 |
| R | 刷新节点定义 |
| 双击画布空白处 | 弹出节点搜索框，输入名称快速添加节点 |

### 2.7 右上角运行区域

| 元素 | 说明 |
|------|------|
| 运行按钮左侧数字 | 一次提交到任务队列的执行次数，默认1；改为5则同一工作流连续执行5次，适合批量生成 |
| 蓝色运行按钮 | 启动当前工作流，按节点连接关系和数据依赖顺序依次执行 |
| 运行按钮旁小箭头 | 展开更多执行选项，入门阶段保持默认即可 |
| 红色叉号 | 停止当前正在执行的任务（提示词填错、参数不合理、生成时间过长时使用） |

### 2.8 右下角画布工具区域

| 工具 | 功能 |
|------|------|
| 箭头按钮 | 选择和移动节点；旁侧小箭头可切换不同画布操作方式 |
| 定位按钮 | 快速找到当前选中的节点，或重新调整整个工作流的观察范围 |
| 百分比数字 | 当前画布缩放比例（如39%），滚动鼠标滚轮自由调整 |
| 地图图标 | 打开小地图，快速查看整个工作流的整体结构 |
| 连线图标 | 控制节点之间连接线的显示/隐藏 |

> 工作流越来越复杂、节点越来越多时，这些工具是快速定位和管理画布的重要功能。

### 2.9 第三方扩展（非默认自带）

| 扩展 | 功能 |
|------|------|
| **Manager** | 使用频率最高的扩展之一，用于安装、更新、管理自定义节点；导入别人工作流提示缺少节点时，通过Manager查找安装；安装后通常需重启ComfyUI并刷新浏览器 |
| Show Image Feed | 展示扩展提供的图片结果面板 |
| K Monitor | 功能随插件版本不同 |
| KGNodes | 功能随插件版本不同 |

> 入门阶段暂不用深入研究这些扩展，不影响理解基础工作流逻辑。

### 2.10 界面地图速记与学习建议

**界面区域速记**：
- **左上角** → 工作流的打开、保存和管理
- **右上角** → 工作流的运行、暂停和任务管理
- **左侧面板** → 快速找到节点、模型、素材及已保存工作流
- **左下角** → 遇到运行问题时优先查看日志
- **右下角** → 节点超出画布范围时，用定位和缩放工具快速找回

**学习路径建议**：
1. 不要一开始就被大量节点和复杂界面吓到
2. 先建立"界面地图"，知道每个区域负责什么
3. ComfyUI官方已内置越来越多经过验证的示例工作流（社区用户长期使用筛选出来的）
4. 入门时不需要从零搭建复杂流程——打开官方工作流 → 根据提示下载模型 → 简单配置 → 直接运行
5. 熟悉运行逻辑后，再逐步修改节点、调整参数，最后搭建属于自己的工作流
